[The Robot Vacuum's Funniest Excuse](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2).

## The line

> "I skipped that corner. The dust bunnies unionized, and I don't cross picket lines."

82 characters, one line, plain ASCII, no trailing newline.

## How it runs

`main.py` uses only the Python standard library. It validates the line
against the 1–120 character gate, then writes it unchanged to
`/output/entry.txt`:

```sh
python3 -P -s main.py
```
